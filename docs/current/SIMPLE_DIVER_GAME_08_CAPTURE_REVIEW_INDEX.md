# Simple Diver Game 08 Capture Review Index

Date: 2026-07-09

Issue: #626
Milestone: Simple Diver Game 08 `Release Candidate`

## Decision

This index names the capture evidence needed for release-candidate confidence. It does not accept baselines, regenerate captures, or change visual source files.

Release-candidate review should use committed current captures, accepted baselines, and comparison sheets as separate evidence types. A missing or invalid required release-path capture is a blocker. A desired extra angle or deferred slice-03 polish is follow-up work.

## Evidence Types

| Type | Paths | Release Meaning |
| --- | --- | --- |
| Current production-slice captures | `visual_captures/production_slice_*/` | Committed current runtime views generated from authored `camera_tests`. |
| Current debug captures | `visual_captures/production_slice_*_debug/` | Committed source/marker review views; useful for diagnosing map/render drift, not player-facing presentation. |
| Focused review captures | `visual_captures/<focused_view>/` | Committed or locally regenerated review evidence for one system or state; not accepted baselines. |
| Accepted baselines | `visual_baselines/production_slice_*_accepted/` | Committed visual baseline targets. Change only through a separate baseline acceptance issue. |
| Baseline comparison sheets | `references/asset_reviews/production_slice_*_visual_baseline_review.png` | Review sheets generated by `compare-all`; evidence of current-vs-accepted drift, not baseline acceptance. |
