# Production Slice 04 Evaluation

Date: 2026-07-06

Issue: #62 `Evaluate production slice 04 against workflow goals`

## Recommendation

Keep `production_slice_04` as a validated reference slice for the lower-left connector / return-loop role.

Do not make it the default preview map. Slice 01 should remain default because it is still the clearest first-area proof with top-water `boat_spawn` entry/extraction. Slice 04 is useful for a different purpose: proving a lower-left loop, longer curved-corridor movement, relay return routing, and source-derived collision in a region that is distinct from slices 01, 02, and 03.

Do not accept a visual baseline in this issue. Baseline status is now tracked by #63 because the baseline tooling currently needs a slice-04 config before accepting or comparing this slice intentionally.

## Role Fit

The slice matches the selected role: connector / return loop, with curved-corridor cleanup as the secondary test.

Good fit:

- It does not repeat the slice-01 first-area boat problem.
- It does not repeat the slice-02 broad lower-right chamber role.
- It does not repeat the slice-03 upper-left stacked-room cluster role.
- It covers a mostly untested quadrant of the full sketch.
- It makes the player cross a longer lower-left loop and return to the east-side relay.

The crop still reads as a bounded review slice rather than a full-map area, but that is acceptable for this stage.

## Source And Collision

Status: pass.

- Source data lives in `maps/production_slice_04.greybox.json`.
- The map is generated by `tools/create_production_slice_04_map.py`.
- The generator records the selected bounds `x=0, y=86, w=88, h=50`.
- The generator sealed crop edges and filled zero unreachable open cells from the relay entry.
- `references/greybox/production_slice_04_source_render_collision_review.png` shows the authored topology, expected collision footprint, and Godot overview agreeing in macro shape.
- `python tools/check_map_parity.py maps/production_slice_04.greybox.json` passed with 2900 terrain cells and 174 collision rectangles.

The stair-stepped curved corridors are visible. That is part of what this slice is meant to test and is not a blocker for reference-slice use. If the project wants smoother lower-left loop silhouettes later, handle that as targeted source-generator cleanup instead of hand-tuning Godot terrain.

## Route And Relay

Status: pass for the current prototype scope.

The route smoke proved that the normal movement controller can swim to all five authored salvage points and return to the relay extraction zone.

The in-water relay/sub visual reads consistently with slice 03: prototype-like, but understandable as the entry and return point. It should not block using slice 04 as a reference slice.
