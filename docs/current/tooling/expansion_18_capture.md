# Expansion 18 Transfer Hub Capture

Run the focused non-headless desktop and iPhone-landscape review capture:

```powershell
& 'C:\Program Files\Godot\Godot_v4.7-stable_win64.exe\Godot_v4.7-stable_win64_console.exe' --path . --capture-expansion-18-transfer-hub
```

The command writes ignored PNG pairs and `capture_manifest.json` under `visual_captures/expansion_18_transfer_hub/` for:

- locked and ready exterior entrance
- interior arrival
- cargo-full core block
- recovered navigation core
- paired exterior return
- canonical-boat result

Each state is captured at desktop `1280x720` and iPhone-landscape `844x390`. These files are local review evidence only; this command does not accept or replace baselines.

Start an isolated manual review immediately before the entrance journey with:

```powershell
& 'C:\Program Files\Godot\Godot_v4.7-stable_win64.exe\Godot_v4.7-stable_win64_console.exe' --path . --review-checkpoint=expansion_18_start
```

The equivalent Web query is `?checkpoint=expansion_18_start`. Checkpoints never mutate the normal profile.
