# Active Tool Icons

These individually replaceable 64x64 SVG assets identify the Scanner, Cutter,
and Shock Prod in the bottom active-tool hotbar. They are presentation-only:
tool ownership, ordering, selection, input, targeting, and behavior remain owned
by the existing runtime controllers.

Keep silhouettes readable at the 44x44 mobile slot size and preserve the
limited cyan, dark-metal, warm-orange, and amber UI palette.
